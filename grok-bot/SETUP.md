# Grok Bot setup

You cannot create a Grok Bot from this repo. Grok Bot lives in the Grok Bot / Cursor app ([x.ai/bot](https://x.ai/bot)). This folder is the pack you paste in.

Need SuperGrok Plus/Heavy or an eligible Cursor plan.

## One evening

1. Create Bot **Scout**. Paste `charter.md` as the description.
2. Send the first-job prompt from `prompts.md`.
3. Review the scan. Optionally teach the read-only Polymarket path.
4. After two scans you trust, create the 10-minute routine. Test run first.
5. Keep live orders off. `ARM LIVE` is a same-day unlock, not a default.

Skills in `skills/` can be uploaded under Settings → Plugins → Yours, or pasted and saved from a finished run (`Save the process we just used as a skill called …`).

## What this is not

The viral $50 → $5,273 clip is not a backtest and has a Community Note on the source post. Completeness gaps of 8%+ are rare on liquid books. Grok fair-value is an estimate, not an edge.
